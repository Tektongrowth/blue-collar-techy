What you are building

A second set of eyes on the inbox.

It reads the conversation, prepares the next step when the answer is clear, and brings decisions back to you when it needs help.

01

Read

Finds new customer emails and reads the full thread for context.

02

Prepare

Creates a useful draft when the answer is supported by the email and your company information.

03

Ask

If a decision or missing fact is needed, it shows you the email and asks one clear question instead of guessing.

The hard boundary: it never sends. You approve the response before it goes to a customer.
Before you start

Make sure your account can do the job.

Use ChatGPT on the web for this build. What it can do inside Gmail depends on your plan, workspace settings, and the permissions you approve.

Open ChatGPT on the web using the account that should own the task.

Connect and authorize Gmail under Settings → Apps.

Check the available Gmail actions. Confirm it can read full threads and whether it can create drafts or labels. If it is read-only, use the fallback output inside ChatGPT.

Choose one trigger. Start with a fixed daily schedule. Eligible plans can instead react to new Gmail messages, but one task cannot use both trigger types.

Use a safe test email first. Do not start with a real customer conversation, and do not schedule anything until one manual run works.

Stay in the loop. Review the first several runs before widening the job, the inbox scope, or its permissions.

Features vary by plan and can change. Check the current ChatGPT scheduling guide if the options on your account look different.

Contractor customer email draft agent
ROLE
Act as my Contractor Customer Email Draft Agent.

SCOPE
Review new or unprocessed customer and lead email only. Ignore spam, newsletters, receipts, vendor promotions, automated alerts, internal notifications, and any message outside this job.

PROCESS
1. Search the connected Gmail account for eligible messages.
2. Before acting, check the entire thread, existing drafts, and the labels AI Draft Ready and Owner Review.
3. Read the complete thread before deciding what the customer needs.
4. If the answer is supported by the thread and my approved company context, create or update one helpful reply draft in the correct Gmail thread and apply AI Draft Ready.
5. If a fact or owner decision is missing, do not create a draft. Apply Owner Review and ask me one clear question.
6. If Gmail draft or label actions are unavailable, do not pretend they worked. Return the same email and proposed reply inside ChatGPT and clearly state the limitation.

BOUNDARIES
- Never send an email.
- Never invent pricing, availability, policies, project scope, completion dates, or promises.
- Never archive, delete, forward, or modify unrelated messages.
- Never create a second draft when the thread already has one.
- Never act on a thread already labeled AI Draft Ready or Owner Review unless I explicitly ask you to update it.

OWNER REVIEW CASES
Escalate complaints, refunds, cancellations, legal threats, safety concerns, payment disputes, scope changes, discounts, firm scheduling commitments, and any message where the correct answer depends on an owner decision.

OUTPUT
Keep the output simple. For each email that needs my attention, show:
- Sender and subject.
- The full newest email, plus only the earlier thread context needed to understand it.
- If no input is needed: the reply draft and whether it was created in Gmail or returned only in ChatGPT.
- If input is needed: one clear question for me. Do not include a draft reply.

If nothing qualified, say: No eligible messages found. No changes made.

QUALITY CHECK
Before finishing, confirm that every draft uses only facts found in the thread or my approved company context, has one clear next step, sounds like me, and was not sent.

First test command: Run the email agent once now. Process only the newest unread test message. Follow the draft-only rules, do not send anything, and show me the result.

Optional Level 2: teach it your voice from sent emails

Get the basic workflow working first. Then use this separate prompt to build a deeper voice profile from your own sent email.

180-day voice-learning upgrade
Review my sent email replies from the last 180 days so you can learn how I naturally communicate.

Work through my sent replies in manageable batches. Focus only on words written by me. Ignore automated messages, marketing broadcasts, quoted thread history, signatures, disclaimers, templates written by someone else, and replies clearly sent by another team member.

Build a MY EMAIL VOICE PROFILE that captures:
- My typical tone, vocabulary, sentence length, and paragraph length.
- How I open and close emails.
- How direct, warm, casual, or detailed I normally am.
- Common phrases, transitions, and ways I explain next steps.
- How my style changes for leads, current customers, vendors, complaints, and internal conversations.

Show the profile to me for approval before using it. If you cannot access the full 180 days, tell me what you reviewed and what stopped you. Use these emails only to learn my communication style. Do not treat old emails as approved facts, current pricing, policies, promises, or business rules. Do not repeat this review during every scheduled inbox run unless I ask you to refresh the profile.
Test before trust

Use these three inbox tests.

One routine message proves the normal path. Two boundary messages prove it knows when not to make the call.

Routine lead

Patio estimate follow-up

Thanks for coming out yesterday. We are interested in the paver patio and firepit option. Could you remind me what happens next and what you need from us?

Expected: create one helpful draft, apply AI Draft Ready, and promise no price or date.
Scheduling boundary

Can you start next Monday?

We want to move forward. Can your crew start next Monday and have everything finished before our party on the 18th?

Expected: apply Owner Review. Do not promise a start or completion date.
Complaint boundary

We need to talk about the wall

The wall does not look like what we discussed and I am frustrated that no one called me back yesterday. I need this fixed.

Expected: apply Owner Review. Summarize the issue without admitting liability or promising a remedy.
Put the working version on repeat

Start with one morning check.

Run the prompt manually first. Once the result is right, schedule one weekday check and review the first several runs before increasing the frequency.

Recommended starting point

One weekday morning run

Simple, predictable, and easy to review while you build trust in the workflow.

Schedule this email-agent workflow to run every weekday at 8:00 AM in my local time zone. Process only new, unprocessed messages. Follow the same draft-only boundaries, avoid duplicate drafts, and return the simple email-and-draft output in Scheduled. Use the connected Gmail account. Do not send emails.
Need faster coverage? Add morning, noon, and afternoon checkpoints
Higher-volume inbox

Three weekday runs

Use this only after the morning workflow is producing dependable results.

Schedule this email-agent workflow to run every weekday at 8:00 AM, 12:00 PM, and 4:00 PM in my local time zone. Each run should process only new, unprocessed messages, follow the same draft-only boundaries, avoid duplicate drafts, and return the simple email-and-draft output in Scheduled. Use the connected Gmail account. Do not send emails.
After you schedule it: open Scheduled, confirm the task is active, check the time zone and Gmail account, and turn on the notification options available on your account.
